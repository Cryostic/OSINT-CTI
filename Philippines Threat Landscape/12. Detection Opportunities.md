# Detection Opportunities

### High-Fidelity Detection Signals

**DLL Side-Loading (T1574.002):**

- Monitor for unsigned DLLs loaded from non-standard paths by legitimate signed executables (e.g., Adobe CEF Helper, Antivirus Binaries).
- Detect mismatches between parent process legitimacy and child DLL origin paths.
- SIEM rule: Alert on `ImageLoad` events where `Signed = FALSE` and the parent process is a known legitimate application.

**Adversary-in-the-Middle SSO Credential Harvesting:**

- Detect impossible travel scenarios in authentication logs (geographically inconsistent session origins within short time windows).
- Monitor for abnormal OAuth token issuance volume from identity providers.
- Alert on session tokens accessed from new device fingerprints following SSO events.

**LNK / Shortcut File Execution (Yokai, Pubload delivery):**

- Alert on execution of `.lnk` files originating from download directories, email clients, or archive extraction paths.
- Correlate `lnk` execution with subsequent `cmd.exe` or `powershell.exe` spawning.

**React2Shell / CVE-2025-55182 Backdoor:**

- Monitor for unusual outbound connections from Node.js server processes.
- Alert on unauthorized `child_process` or `vm` module invocations in React SSR environments.
- Audit server-side logs for anomalous prototype chain manipulation patterns from December 2025 forward.

**Ransomware Pre-Encryption Signals:**

- Alert on mass file staging or archive creation in unusual directories.
- Detect shadow copy deletion commands (`vssadmin`, `wmic shadowcopy`).
- Monitor for unusual credential access to backup systems or domain controllers prior to encryption events.
