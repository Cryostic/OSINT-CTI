- Subject line: "National ID Replacement - Ready for Release"
- Follow-up calls from: `09605870320`, `09485376272`
- Google Meet links used: `meet.google.com/vso-zdxt-kfm`, `meet.google.com/tdb-vvnd-ino`
- Date/time: 11 Apr 2026, approx. 3:00-3:02 PM

No personal data was provided and no software was installed. I'm submitting this report so PSA can add these indicators to any active tracking of this campaign, and so the associated Gmail account and Meet links can be reported to Google for takedown.
