## 3. Analytical Synthesis

1. **Operational pattern — "register tonight, send tomorrow":** registration → TLS provisioning → delivery within ~35 hours is consistent with a rehearsed, kit-based deployment, not bespoke development. (Assessment, Medium-High)
2. **Origin-hiding:** Cloudflare proxy + no PTR records conceal the true server — a deliberate resilience measure used in phishing (raises takedown and legal-identification cost). (Assessment, High)
3. **Wildcard certificate:** `*.ncapmmda.skin` suggests the operator planned (or stages) subdomains — common for phishing kits that rotate subdomains per campaign. (Assessment, Medium)
4. **Budget registrar + 1-year registration + niche TLD:** lowest-cost disposable infrastructure; consistent with the low-sophistication, high-turnover operator profile assessed in `04. Attribution and Pattern Mapping.md`. (Assessment, Medium-High)
5. **No email records:** the domain is a web-application target (the fake "settlement" portal per hypotheses H1–H3 in `03. Technical Analysis.md` §3.4). (Assessment, Medium)
