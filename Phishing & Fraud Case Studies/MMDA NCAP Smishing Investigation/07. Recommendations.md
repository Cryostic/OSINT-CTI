## Priority Ordering Summary

1. **Immediate:** A-1 → A-2 → A-4 (protect self; feed investigation).
2. **Detection (12-24h):** B-1 + B-2 + C-1 (rules, blocklist, hunt).
3. **Awareness (1 week):** B-3 + A-5 (human layer — the decisive control for smishing).
4. **Readiness (ongoing):** B-4/B-5/C-5 (process + playbooks).

**Pyramid-of-Pain note:** This campaign's artifacts (domain, sender alias) are cheap and disposable; only the **TTP layer** (playbook, template fingerprint, verification behavior) provides durable defense. All long-lived controls above intentionally target TTPs.
